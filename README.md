# Jeevasree S — Portfolio

A responsive, dark-tech personal portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `jeevasree-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public website URL.

## Personalise
- Update text and links in `index.html`.
- Adjust colours and layout in `style.css` (CSS variables are at the top).
- The project currently uses a CSS-made dashboard illustration instead of a screenshot.
